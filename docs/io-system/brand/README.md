## Production rules

Preserve the approved pixel logo geometry. Use the company definition and approved short line. Keep atmosphere in art and clarity in the interface. Use actual current event/registration/provider/download states. Do not market planned features, synthetic people or unverified model/hosting claims as live facts.

The refreshed DeepSeek Harness is a separately versioned native Terminal preview. A branded source archive is **source, not an installer**. A public download needs reviewed app identity/update channels, real artifacts, signatures where applicable, platform labels, checksums and recovery tests. The OpenCode web connector remains a separate protocol and its unverified execution controls are paused.

## Rebuilding and provenance

`build_brand_book.py` uses ReportLab, local source art and the bundled font files to generate the PDF and page index under `output/pdf/`. The page index identifies the two moodboards. The PDF was rendered with Poppler and every page inspected; selected pages were exported directly as moodboard PNGs. PDF rendering/review files are outside the Git source tree.

Fraunces and Inter come from the official Google Fonts repository. Their OFL license files are included under `fonts/`. The five static/variable font sources support the HTML/book; this folder does not change the production application font configuration. A machine-readable asset manifest records hashes, dimensions and provenance. Preserve the originals and label proposals separately.
